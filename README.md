# beta-room

A lab for beta-stage projects and functional prototypes.

## What is this?
`beta-room` is my personal space to quickly build, test, and iterate on small digital experiments.

## Goals
- Ship small MVPs fast
- Learn by building in public
- Keep things simple, usable, and focused

## Experiments
- `exp-001-micro-planner` (in progress) — A 3-tasks-per-day micro planner with a clean UI.

## Tech stack (default)
- Web-first prototypes (Vite / React or plain HTML/CSS/JS)
- Minimal dependencies
- Local-first (no login) when possible

## How to run
Each experiment has its own folder and instructions inside.
